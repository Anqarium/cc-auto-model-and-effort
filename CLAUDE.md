# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Durum

Depo henüz başlangıç aşamasında: yalnızca `README.md` (sadece proje adı) ve `.gitattributes` (`* text=auto`, LF normalizasyonu) içeriyor. Kaynak kod, build sistemi, test altyapısı veya bağımlılık manifesti yok; bu yüzden build/lint/test komutu da tanımlı değil.

Proje adı (`cc-auto-model-and-effort`) Claude Code için otomatik model ve effort seçimi konusuna işaret ediyor; ancak henüz bunu doğrulayan bir tasarım veya kod yok. Mimari, dil ve araç seçimleri belirlendiğinde bu dosya güncellenmelidir (komutlar, mimari, tek test çalıştırma yöntemi).
